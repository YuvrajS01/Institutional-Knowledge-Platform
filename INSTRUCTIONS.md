# Agent Instructions

Read the full autonomous implementation instructions at:

`.agent/INSTRUCTIONS.md`

Then follow `.agent/AGENTS.md`.

Inspect the repository and Git state before changing anything. Determine the highest-priority unblocked task from `.agent/planning/TASK_MANIFEST.md` and implement tasks autonomously in dependency order.

Do not ask for routine implementation decisions. Test, review, document, and commit each completed task according to the repository policies.


Use a task branch, run verification, create an atomic commit, push, and open a pull request. Do not merge into `main` without the repository's required approval gate.

For model handoffs, read `.agent/planning/PROJECT_STATE.md` after the main agent instructions and verify it against Git.
